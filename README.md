# Global Group RaaS – Malware Analysis

This repository contains a technical analysis of the ransomware
**Global Group RaaS**. The analysis includes static and dynamic
investigations, IoCs, screenshots, and a YARA rule.

## Contents
- report/overview.md — Overview and Summary
- report/static-analysis.md — Strings, Imports, PE-Strucure
- report/dynamic-analysis.md — Behavior in the sandbox
- report/encryption.md — Encryption methods
- IOCs/ — Indicators of Compromise
- yara/global_group_raas.yar — YARA-Rule
- media/ — Screenshots

## Note

**This repository contains no malware samples or executable malicious code.** Only analysis materials (screenshots, IoCs, pseudocode) are provided.
